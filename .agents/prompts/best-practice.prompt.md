## 指令

開始前，閱讀 `../instructions/instruction.instructions.md` 內的規範，理解正確的文件結構、命名規則與連結方式。

將使用者指定的檔案精簡成簡單版的 Best Practice，不用說明前因後果，只要說明什麼是推薦寫法，Bad & Good，什麼去哪參考詳細介紹。

範例代碼可以精簡化，將多種好壞範例集中在一個 code block 內，並用註解說明哪個是好哪個是壞，好壞可以分以下等級：

- Bad: 明顯不推薦的寫法，會造成錯誤或不符合規範
- Good: 推薦的寫法，符合規範
- OK: 可接受的寫法，沒有明顯錯誤，但不是最佳作法

開始前可備份原擋，完成後刪除備份檔案。

過程中發現斷掉的連結或不正確的檔案名稱，嘗試修正。

## 驗證

- 結束後，重新檢視一次原檔案，確認符合規範。
